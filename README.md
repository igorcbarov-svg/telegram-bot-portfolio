# Telegram-бот: Визитка + Приём заявок

Демонстрационный проект Telegram-бота на Python (aiogram 3) для портфолио. 
Бот выполняет роль визитки, показывает прайс и принимает заявки от клиентов с уведомлением администратора.

## 🚀 Функционал
* **Главное меню:** Удобная навигация с помощью Reply-кнопок.
* **Прайс-лист:** Вывод услуг с интерактивной кнопкой (Inline) для заказа.
* **Форма заявки (FSM):** Пошаговый сбор данных (Имя -> Контакт).
* **Уведомления:** Мгновенная отправка новой заявки администратору в Telegram.

## 🛠 Стек технологий
* Python 3.11+
* Aiogram 3 (асинхронный фреймворк)
* FSM (Машина состояний)
* Pydantic Settings
* Git
